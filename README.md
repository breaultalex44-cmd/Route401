## 🎯 Key Features & Capabilities

### 🌐 1. Global & Canadian Database Matrix

* **Comprehensive Location Tracking:** Features over 75+ locations spanning Canadian provinces/territories and major international global capitals[cite: 9].
* **Advanced Filtering & Sorting:** Real-time search filtering, region toggling (Canada vs. International), and sorting by population, density, HDI, crime index, and GDP per capita[cite: 9].

### 🍁 2. "Remember" Feature (2028 Focus)

* **Custom Regional Notes & Folders:** Save cities into custom folders (General, Bucket List 2028, Travel 2028, Business) with specific reminder dates and checklist tracking[cite: 9].
* **Local Persistence:** All saved locations and 2028 notes persist securely in browser `localStorage`[cite: 9].

### 🛰️ 3. GPSRouter v3 & Portable Thumb Tab

* **Algorithmic Econometric Modeling:** Enter any unlisted town or global metropolis for instant synthesis of GDP parity, regional employment, trade indexes, and socio-economic metrics[cite: 9].
* **Portable Thumb Tab:** Export and import your entire 2028 remembered database as a secure JSON file across devices[cite: 9].

## 📖 System Manual & Wiki

### System Architecture

Route401 operates entirely client-side using vanilla web technologies and responsive fluid layouts optimized for both compact mobile viewports (such as the Moto G Play ratio simulator) and full desktop displays[cite: 9].

### Database & Filtering

The central database maps critical economic factors including population density, Human Development Index (HDI), crime index ratings, and GDP data[cite: 9]. Search queries dynamically parse through records in real time[cite: 9].

### GPSRouter v3 Algorithm

When querying an unlisted location, GPSRouter v3 employs a seeding hash algorithm on the input string to generate consistent, realistic econometric forecasts for population, density, and financial indices tailored to the modeled geographic country or region[cite: 9].
