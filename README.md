## 🎯 Key Features & Capabilities

### 🌐 1. Global & Canadian Database Matrix

- **Comprehensive Location Tracking:** Features **100+ locations**, combining 50+ Canadian cities, towns, and territorial hubs with 50 major international global metropolises across 6 continents.
- **Advanced Filtering & Sorting:** Real-time search filtering, region toggling (Canada vs. International), and sorting by population, density, HDI, crime index, GDP per capita, and total GDP.

### 🌲 2. "Remember" Feature (2026–2027 Focus)

- **Custom Regional Notes & Folders:** Save any location into custom folders (General, Bucket List 2026–2027, Travel 2026–2027, Business) with specific reminder dates, notes, and checklist tracking.
- **Local Persistence:** All saved locations and 2026–2027 itinerary notes persist securely in browser `localStorage`.

### 🛰️ 3. GPSRouter v3 & Portable Thumb Tab

- **Algorithmic Econometric Modeling:** Enter any unlisted town, rural municipality, or world metropolis for instant synthesis of GDP parity, regional employment, trade indexes, and 2026–2027 socio-economic projections.
- **Portable Thumb Tab:** Export and import your entire 2026–2027 remembered database as a portable JSON thumb file across devices and offline platforms.

## 📖 System Manual & Wiki

### System Architecture

Route401 operates entirely client-side using vanilla web technologies and responsive fluid layouts. It features an integrated PC/Laptop Viewport Simulator slider designed to emulate handheld mobile devices like the Moto G Play (2024) alongside full desktop displays.

### Database & Filtering

The expanded central database maps critical economic factors including population density, Human Development Index (HDI), crime index ratings, total GDP, and GDP per capita across both Canadian and global hubs. Search queries parse dynamically through records in real time.

### GPSRouter v3 Algorithm

When querying an unlisted location, GPSRouter v3 employs a seeding hash algorithm on the input string to generate consistent, realistic econometric forecasts for population, density, and financial indices tailored to the modeled geographic country or region for 2026–2027 planning.
